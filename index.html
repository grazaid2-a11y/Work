              GDELT 2.0

              Global news on biology & outbreaks

              Recent articles from GDELT DOC 2.0 (api.gdeltproject.org/api/v2/doc/doc). Results are media reports indexed by GDELT, not verified scientific facts; dates show when GDELT first saw each article, and near-duplicate headlines are hidden. Requests are spaced ≥5s because HTTP 429 is common.

                Source: GDELT Project · GDELT 2.0 notes

                Biodiversity (GBIF)

                Species explorer

                Taxonomy and occurrence records from GBIF. Dots show the first 300 georeferenced records returned, not a range map: records reflect where people sample, and mix observations with museum specimens. Conservation status (IUCN) is not included because it needs credentials.

                Molecular (UniProt)

                Protein explorer

                Searches UniProtKB. “Reviewed” entries are manually curated (Swiss-Prot); “unreviewed” are automatic annotations. Structures are linked, not rendered, and AlphaFold models are predictions, not experimental structures. Amino-acid composition is computed here from the downloaded sequence.

                Scholarly discovery

                Literature search & reading list

                Searches OpenAlex, Europe PMC or Crossref directly from your browser. Retraction flags are only shown when the source reports them (OpenAlex, Europe PMC); Crossref results carry no flag here, which is not proof a paper is sound.

                Reading list

                Analysis workbench

                Import, check & analyse your data

Excel (.xlsx/.xls) is read with the SheetJS library, loaded from cdnjs when you pick such a file (the file itself stays local); only the first non-empty sheet is imported.

                  Source health

                  Source registry & live checks

                  Endpoints and notes below were written from documentation knowledge and have not been verified in this build. “Check now” runs a real request from your browser and records status, latency and whether the browser could read it (CORS). Licences and terms: follow each provider link before reuse.

                  Evidence intelligence

                  Research-gap indicators

                  Counts publications per year, country and type from OpenAlex for your query (optionally compared with a second query). Low counts are a prompt to investigate, not proof of a gap: keyword search misses synonyms, non-English work and unindexed literature.

                  Methods library

                  Protocols (private, versioned)

                  Your own protocols, stored only in this browser. Every save creates a new version. These are user-written procedures, not published or validated methods; cite the original source in the citations field. protocols.io is not integrated (it requires an access token).

                  Lab notebook & tasks

                  Notebook, audit trail & task board

                  Local to this browser: no accounts, sharing or collaboration. Notebook entries are append-only and timestamped; to correct one, add an amendment, so the history stays intact. Clearing browser data deletes everything, so use the package export as a backup.

                  Task board

                  Dataset catalogue

                  Find open datasets (Zenodo)

                  Searches public Zenodo records and shows licence, date, type, file formats and size so you can judge reuse. Licences are as declared by depositors: confirm before reuse. Quality is not assessed.

                  Reproducibility

                  Checklist & research package

                  The checklist inspects what is actually in this browser right now. The package is a JSON file of your notes, plan, protocols, references and analysis log. Imported data is included only if you tick the box, and only share data you are licensed to redistribute.

                  Knowledge graph

                  Your evidence graph

                  Built only from what you have saved here: papers, their authors and journals (from OpenAlex/Crossref/Europe PMC metadata), protocols, and notebook entries. Solid lines are direct links from that metadata or made by you; dashed lines are inferred (e.g. two papers sharing an author) and are not evidence of scientific relatedness. Click a node to see why it is connected.

                  Global indicators

                  Choropleth & threshold monitor

                  World Bank indicators by country: the most recent reported values, not live data; reporting years differ between countries and many are modelled estimates. Thresholds are checked when you load the map; there are no background alerts or subscriptions. Country shapes come from a public GeoJSON file (loaded from GitHub) or one you supply.

                  3D structure

                  Molecular structure viewer

                  Real atomic coordinates rendered with 3Dmol.js (loaded from cdnjs). PDB entries are experimentally determined (X-ray, cryo-EM, NMR) and come from RCSB. AlphaFold models are computational predictions; trust varies by region, shown by the pLDDT confidence colours. Nothing is invented or smoothed here: what you see is the file’s coordinates.

                  What this file is made of
                  • HTML — page structure, sections, accessibility
                  • CSS — colors, layout, themed panel backgrounds, responsive grid
                  • JavaScript — API fetches, search, charts, caching
                  • SVG — population line chart (drawn in the browser)
                  • JSON — data format returned by World Bank, WHO, GHO, NASA, iNaturalist, GDELT
                  • CSV — Our World in Data grapher downloads
                  • localStorage — short-term cache so refresh is faster offline-friendly

                  No React, Python, or build tools required — one .html file is enough for the browser.

                  How numbers are labelled. Published figures are stated by the source. Calculated values are arithmetic on those figures. Empty means the source had no value — never filled with zero.
